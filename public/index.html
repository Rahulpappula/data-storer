Enterprise-Grade Security

We implement strict cryptographic and storage guardrails to ensure your personal contact ledger remains entirely private.

Secure Key Derivation

Passwords and PINs are hashed using industry-standard Blowfish-derived BCrypt salting routines, ensuring offline brute-force immunity.

JSON Web Token (JWT) Session Guard

Your authentication sessions are verified and encrypted using stateful JSON Web Tokens, automatically expiring after 24 hours of inactivity.

Zero-Knowledge WebAuthn Keys

Biometric public keys are registered locally and cryptographically signed on-device. Your actual fingerprint or facial map never leaves your hardware.
